# Apuração 2026

Painel de acompanhamento da apuração das eleições de 2026, com dados oficiais do Tribunal Superior Eleitoral (TSE) e malhas do Instituto Brasileiro de Geografia e Estatística (IBGE).

Acesse: https://luciano-victor.github.io/apuracao2026/

A página é estática: cada navegador consulta diretamente os arquivos públicos do TSE, com atualização automática a cada 45 segundos. Os dados exibidos são os da apuração oficial e podem sofrer retificação.

Desenvolvido por Luciano Victor com apoio de IA (Claude, Anthropic).
